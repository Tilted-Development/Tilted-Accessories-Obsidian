# Have you ever wanted to *decoin* the term **Crying Obsidian**?

Well, with **Tilted Development**’s shiny new plugin, **Tilted Accessories**, now you can!

As of version `1.0.1`, here's what you can do:

---

## ✨ Features

### 🔗 Link Favicons
Add a tiny site icon next to your links!

Just include `*favicon` in the link title.

Example:

```markdown
[Tilted Development Ltd.](http://tilted.42web.io "The NERDS *favicon")
````

Will display with a favicon, but the title is still only `"The NERDS"`!

This also works with
````markdown
```favicon
https://www.google.com
```
````

---

### 🖼 Link Previews (Thumbnails)

Hover over a link to see a live website preview!

Just include `*thumbnail` in the title — and yes, **it works with favicons too!**

Example:

```markdown
[Wikipedia](https://en.wikipedia.org "Wikipedia - the gateway to knowledge *thumbnail")
```

---

## ⚙ Notes

- Works on both desktop and mobile (previews are desktop-only).
    
- Titles are untouched — extras like `*favicon` or `*thumbnail` are stripped from tooltips.
    
- Automatically runs on layout change, no setup needed.
